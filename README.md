# Eason's Tap (`easonliuuuuu/tap`)

Homebrew formulae and Windows Scoop bucket for Eason Liu's projects.

## Installation

### Homebrew (macOS & Linux)

```sh
brew install easonliuuuuu/tap/vsfleet
```

### Scoop (Windows)

```powershell
scoop bucket add easonliuuuuu https://github.com/Easonliuuuuu/homebrew-tap
scoop install vsfleet
```
